# 提审材料索引

| 文件 | 用途 |
|---|---|
| `提审包说明.md` | 类目、配置、版本描述、审核路径、风险和待办 |
| `审核话术.md` | 首轮审核备注与常见质疑回复 |
| `版本描述.txt` | 可直接粘贴到版本描述 |
| `截图清单.md` | 提审截图内容与截图纪律 |
| `隐私保护指引填写.md` | 微信后台隐私保护指引填写建议 |
| `app-icon-144.png` | 小程序头像上传文件 |
| `app-icon-1024.png` | 高清图标备份 |

正式提审前，必须完成 `提审包说明.md` 中的配置项，并用微信开发者工具生成真实截图；当前仓库不伪造审核截图。
