## 3. 全局功能说明

### 3.1 导航

桌面端左侧导航顺序：

1. 大师PK
2. 大师的选股池
3. 巴菲特的早餐
4. 芒格教你读财报
5. 缠中说禅看短线
6. 纳瓦尔知识学堂
7. 鱼大基础面研究
8. 行业周期分析

移动端底部导航和功能大厅保持相同顺序。

### 3.2 AI 调用与免费额度

- 无用户 Key：默认 10 次免费体验，使用站长服务端 Key。
- 第 10 次可用；第 11 次触发 `ensureAiReady()`，弹出 AI 设置。
- 有用户 Key：不消耗免费次数，直接使用用户配置。
- 免费次数同时写入：
  - `localStorage`：`thinktank_free_quota`
  - Cookie：同名
  - 取两者较大值，防止刷新重置。
- 服务端另有未带用户 Key 的防滥用兜底：
  - 当前设置为每 IP 每日 40 次。
  - 跨接口共享计数。
  - 第 41 次返回 HTTP `429`。
  - 多实例/Vercel 环境为尽力而为，本地单实例测试可精确验证。

### 3.3 分享机制

- 左侧底部“分享给好友”位于“入群聊一聊”上方。
- 两个按钮高度一致。
- 分享按钮使用分享图标，带轻微摇摆和光圈动效。
- 用户主动完成完整功能输出后计数：
  - 第 1 次不弹提示。
  - 第 2 次完整输出后，顶部出现一次分享提示。
  - 只出现一次，记录在 `thinktank_share_prompt_seen_v1`。
- 分享面板默认文案包含网站地址和推荐语。
- 关闭方式：
  - 点击面板外空白处。
  - 点击右上角关闭按钮。
  - 按 `Esc`。

### 3.4 数据真实性原则

- 行情、财报、估值、行业指数来自公开数据层。
- 行业周期模块中，行业库存、现货价格、开工率等无法自动获取时，必须标为“数据不足”或“待验证”。
- AI 不得编造精确数字。
- 缺失数据会降低周期评分覆盖率与置信度。

- 步骤：
  1. 清空用户 Key。
  2. 设置免费次数为 9。

  4. 再次发起基本面分析。
- 预期：
  - 第一次请求正常发起，次数变为 10。
  - 第二次不发请求，弹出 AI 设置。
  - 有用户 Key 时，即使剩余 0 次仍允许请求，且次数不变。

- 步骤：使用同一测试 IP，无用户 Key，跨接口发送 41 次请求。

## 12. 行业周期分析

### 功能细节

- 输入 A 股名称或 6 位代码，不支持非 A 股。
- 支持补充产品价格、库存、开工率等行业数据。
- 盘前或休市时若东财现价字段为 `0`，自动使用昨收价并明确标注“上一交易日收盘”，不误报无行情。
- 网关返回 HTML/非 JSON 错误页时，前端显示“分析服务暂时不可用”，不透传 JSON 解析异常。
- 中文输入支持 250ms 防抖模糊搜索；输入“宇树”候选应显示“宇树科技-W / 688836”。
- 东财行情失败自动重试一次；行情失败不写入 60 秒负缓存，避免连续重试被同一失败结果阻塞。
- 输出：
  - 一句话结论
  - 周期属性
  - 周期传导链
  - 九维周期仪表盘
  - 周期阶段波浪图
  - 周期拐点
  - 行业到公司传导
  - 股票位置
  - 行业周期 × 股票周期四象限
  - 观察清单
  - 证伪条件
  - 最终裁决
- 九维仪表盘为雷达图 + 可展开指标行。
- 公司传导默认显示 4 个关键信号，其余折叠。
- 未来观察清单默认展开。
- 证伪条件默认收起。
- 数据来源和关键数据缺口默认收起。
- 最终判断包含五档刻度和判断摘要。

### 回归用例

- [ ] IC-01 输入 `600328` 可分析。
- [ ] IC-02 输入 A 股名称可解析。
- [ ] IC-03 输入 `AAPL` 明确提示仅支持 A 股。
- [ ] IC-04 波浪线完整穿过五个阶段节点。
- [ ] IC-05 雷达图显示 7 个计分维度。
- [ ] IC-06 九维指标行默认收起，点击可展开证据。
- [ ] IC-07 缺失指标显示“数据不足”，不编造数字。

## 20. 已知限制

- AI 输出具有非确定性，测试应验证结构、边界和业务规则，不依赖固定措辞。
- Vercel 多实例环境下，进程内每日免费兜底只能尽力而为；严格限制需要 Redis、数据库或账号级额度。
- 行业库存、现货价格、开工率等并非所有行业都有稳定公开接口，必须允许“数据不足”。
- 新闻、行情、财务接口可能临时不可用，页面应降级而不能白屏。
- 分享入口和分享提示属于浏览器本地行为，清理本地存储后会重新触发。
