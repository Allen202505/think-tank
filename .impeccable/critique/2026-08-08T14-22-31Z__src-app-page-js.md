# 大师吵股 · 首页 UI 综合审查（impeccable critique）

**总分：30 / 40**

## 二、设计特异性

**Competent**（距 Distinct 只差"层级收敛 + 可读性达标"）。宋体衬线 + 金色 + 纸感 + 等宽注解层是经过思考的学院风语言，裁决投票条/打字机/邀请三阶段是定制设计；但深色对比度缺陷、双主 CTA、微字号过载拉回 Competent。

## 三、构图与层级

- 头部瘦身正确；但 `.header` 出现两份定义（补丁式迭代）。
- **侧栏权重颠倒**：金色通栏 `.invite-entry`（低频"邀请大师"）视觉权重大于高频"选成员"。
- 提问卡顶线用 `--bull` 绿色 accent，与品牌金/讨论卡不一致，金融语境下绿色=看多，易误读。
- 讨论区是全局最好看的部分；空态 ⚖️ 过静，首次访客难意识到主循环入口。
- 错误提示（提问卡顶）与追问输入（讨论卡底）断裂，用户出问题时找不到原因。

## 四、字体

- 衬线=阅读主声部、无衬线=UI 控制、等宽=注解层，方向正确，但覆写不完整（question-input 仍衬线，系统实际"三字体混排"）。
- **对中文，monospace 回退到系统无衬线，"等宽"语义在 CJK 上不成立**，效果只是"又小又稀的标签"；9-10px accent 文字低于 AA。

## 五、色彩与主题

- 金色单一 accent 纪律好；但浅色 accent 小字 4.1:1 不达 AA。
- **深色主题 P0**：`--text-muted #3a3a5a` 对深底仅 1.8:1，占位符/侧栏提示/成员风格/空态/标题全不可读；卡片对页面 1.05:1，层级靠默认模糊肖像撑起来。

## 六、优先级问题

**[P0] 深色模式次级文字不可读**（A+B 独立一致）
- 问题：`--text-muted #3a3a5a` 对 `#0a0a0f` ≈1.8:1；`--border-subtle #252535` 约 1.2:1。
- 影响：暗色用户看不到占位符、提示、成员风格、空态、图标按钮；比亮色体验落差巨大。
- 修：`--text-muted` → ≈`#9b98ad`（≥4.5:1），`--border-subtle` → ≈`#2c2c40`，复查占位符/`.master-style`/`.empty-state p`/`.sidebar-hint`/`.icon-btn`。
- 命令：`$impeccable audit` → `$impeccable polish`

**[P1] 亮色 accent 小字对比不足**
- 问题：`--accent #9a7830` 对卡底 4.1:1，用于 9px 卡片标题、15.5px 裁决标题、14px 单聊对象名、10px 链接。
- 修：accent 文字统一深金（≥`#7d5f1f`）；小字标注层级两档 11/12px。
- 命令：`$impeccable typeset`

**[P1] 两个同权重金色主按钮**
- 问题：`.invite-entry`（侧栏金色渐变 800 字重）与 `.btn-submit`（提问卡同段渐变）同级；`.chat-mode-btn.active` 也是金底。
- 影响：首次访客分不清主路径；低频"邀请"压过高频"选成员"。
- 修：`.invite-entry` 降为幽灵按钮（透明底+金描边+金字，去渐变去加粗），金色渐变只留 `.btn-submit`。
- 命令：`$impeccable layout`

**[P1] 邀请大师失败时错误不可见**
- 问题：`handleInvite` 失败走 `setError`（渲染在提问卡内），被弹窗遮罩盖住。
- 修：弹窗内加 `.invite-error` 就近显示失败原因 + 重试。
- 命令：`$impeccable harden`

**[P1] master-row 键盘焦点不可见**
- 问题：成员行 role=button+tabIndex=0 但无 `:focus` 样式；输入控件 outline:none 仅靠边框变色。
- 修：统一 focus-visible 样式（accent 2px ring）。
- 命令：`$impeccable audit`

**[P2] 移动端提问卡被侧栏压到首屏外**
- 问题：DOM 中 sidebar 在 main 前，≤900px 单列后 邀请按钮+横滑成员条+bg-control+提示 全排在提问卡上方。
- 修：单列时 `.main{order:-1}` 提问卡先行；`.master-more-btn` 触屏 opacity 提到 0.8（`@media (hover:none)`）。
- 命令：`$impeccable adapt`

**[P2] 微字号标签过载 + 弹窗焦点管理 + 性能**
- 8-11px 等宽标签铺满（card-title 9px / sidebar-count 9.5px / host-label 9px…），信息靠缩小字号解决；建议元信息两档字号 11/12px，删除重复计数。
- 6 个弹窗无焦点陷阱/移焦/aria-labelledby/aria-live；建议统一弹窗焦点管理 + `role="alert"`。
- 性能：默认全屏模糊背景（blur16+saturate+scale）持续合成成本；favicon.ico 与 favicon.png 各 1.67MB（首页多下 3.3MB）；建议压缩/换小图标，背景默认降 opacity 或改 none。
- 命令：`$impeccable typeset` / `$impeccable harden` / `$impeccable optimize`

**[P3] 一致性/技术债**
- 圆角 4/6/8px 混用未统一；两份 `.header` 定义靠 !important（520px 断点 padding 失效）；`.mode-switch/.mode-btn` 整段死 CSS；二维码 fallback 文案渲染反引号；无 prefers-reduced-motion；Space 键不响应；textarea 无 label。
- 命令：`$impeccable polish` / `$impeccable distill`

## 七、人物走查

**首次访客（桌面浅色）**：默认 5 位已选+具体示例很好；失败点：① 双金色按钮稀释主路径；② 空态 ⚖️ 太轻、首屏无"辩论"画面感；③ 默认模糊巴菲特肖像抢注意力（"背景是什么"先于"我要问什么"）。

**深度用户**：历史/清除/追问 Enter/画像编辑都好；失败点：① 追问失败错误在提问卡顶，远离讨论流底部；② 打字机无跳过/加速；③ 移除虚拟大师无确认。

**手机用户**：① 提问卡被整段侧栏压到首屏外；② ⋯ 按钮 45% 透明+hover 才现，触屏等于没有；③ 单聊单选/群聊多选切换无视觉提示。

## 八、次要观察（快速胜利）

1. 删除提问卡 footer 与侧栏重复的"已选 X/Y"。
2. 🕘 历史图标换清晰图标或补文字。
3. 按钮加载文案与 loading-state 重复，按钮可简化为"召集中…"。
4. 主 textarea 支持 Enter 提交、Shift+Enter 换行，并提示。
5. 追问/邀请失败错误就近呈现。
6. 清理死 CSS（.mode-switch/.mode-btn、重复 .header/.master-style）。
7. 默认背景建议 none 或 opacity 0.15（纸感是卖点）。
8. en 模式弹窗中文混杂（邀请/编辑/历史/补充/移除），MasterProfileModal 两分支相同。
9. metadataBase 占位域名（think-tank.example.com）需在生产设为真实域名。
10. 移除虚拟大师前加确认。

## 九、能解锁更好设计的提问

1. 产品是"娱乐/内容产品（看吵架、晒海报）"还是"决策参考工具（带走结论）"？决定讨论流该沉浸式还是结论前置。
2. 模糊肖像背景默认值该是 none 吗？纸感是卖点，别让影像抢版式。
3. "邀请大师"是增长亮点还是深度功能？是否该做弱入口，把金色唯一留给"召集智囊团"？
4. 单聊/群聊两套选择逻辑是否值得更强的模式化视觉（如单聊时行尾"设为对象"）？
5. 深色主题是坚持"纸感"重做层级，还是转向"书房羊皮纸+琥珀光"深色世界？
6. 讨论流是否加"跳过/2x/暂停"打字机控制？
