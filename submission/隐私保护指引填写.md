# 微信公众平台隐私保护指引填写建议

以下文字用于微信公众平台“用户隐私保护指引”或“小程序用户隐私保护指引”配置，实际字段以平台当前表单为准。

## 开发者处理的信息

### 1. 用户主动提交的内容

- 信息类型：用户填写的新闻标题与正文、公司名称或代码、行业补充材料、指数剔除条件、股票代码、财报链接、财报原文、研究关注点和提问。
- 使用目的：生成本次新闻分析、行业周期分析、上证指数脱水、基本面研究、供应链瓶颈分析、财报阅读或财经通识内容。
- 处理方式：用户主动提交后，通过微信云函数转发至本项目的服务接口；业务数据库不保存问题正文或财报原文。
- 用户控制：用户可以不提交、随时退出；本地研究记录可在“关于与隐私”中清除。

### 2. 微信用户标识（OpenID）

- 信息类型：微信云函数运行时可获取的 OpenID。
- 使用目的：防止恶意刷量，执行每日免费次数限制。
- 处理方式：服务端先进行 SHA-256 哈希，仅在内存中保存与当天计数相关的短期哈希值；不用于用户画像、推荐或营销，不写入业务数据库。

## 不收集的信息

- 不收集手机号、身份证、银行卡或支付信息。
- 不收集精确位置、通讯录、聊天记录、相机、相册或麦克风内容。
- 不收集证券账户、真实持仓、交易记录或资产信息。

## 第三方服务

可能涉及的第三方处理方：

1. 微信云开发：承载小程序云函数及其必要的平台运行日志。
2. 本项目部署与网络服务：处理小程序云函数发起的 HTTPS API 请求。
3. AI 模型服务：处理用户主动提交的文本，以生成本次研究内容。
4. 公开数据源：东方财富、腾讯证券、新浪财经、Yahoo Finance 等，用于取得公开行情、指数、财务或网页材料。

平台与服务商可能按照其合规规则保留必要的运行和安全日志。业务系统不将用户输入用于训练自有模型。

## 用户权利

- 用户无需注册即可使用主要功能。
- 用户可以在“关于与隐私”中清除当前设备的全部研究记录。
- 用户可以通过项目公开反馈地址提出隐私问题或删除请求。

## 产品内隐私说明位置

```text
首页 → 关于与隐私 → 隐私保护说明
```

## 重要提醒

正式提交前，必须把“项目部署与网络服务”“AI 模型服务”和公开数据源的名称按实际供应商填写为具体名称，并确认微信云开发、部署服务、模型服务商和各数据源的日志保留规则。不要填写超出实际处理范围的承诺。
