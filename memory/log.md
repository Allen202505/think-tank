### 部署后：大师头像丢失 + 重定向死循环（ERR_TOO_MANY_REDIRECTS）
**背景**:
- 部署后部分大师真实头像丢失（图片加载失败）。
- 浏览器 Console 报错：`Failed to load resource: net::ERR_TOO_MANY_REDIRECTS`，涉及 `/avatars/*.jpg` 与 `/favicon.ico`。

**决策**:
- 头像资源统一使用 ASCII 路径 `/avatars/*`，避免中文路径 `/头像/*` 在部分部署/CDN 环境兼容性问题。
- 站点规范域名继续统一为 **非 www**：`https://yieldglide.com/`。

**实现**:
- 代码侧（已推送到 GitHub）：
  - `src/data/masters.js`：预置大师头像从 `/头像/*.jpg` 改为 `/avatars/*.jpg`。
  - `scripts/sync-avatars.mjs`：构建前把 `public/头像` 同步复制到 `public/avatars`。
  - `package.json`：新增 `prebuild` 执行同步脚本。
- 排查发现线上重定向互相打架导致死循环：
  - Cloudflare：将 `yieldglide.com/*` 重定向到 `www.yieldglide.com/*`（非 www → www）。
  - Vercel（`vercel.json`）：将 `www.yieldglide.com/*` 重定向到 `yieldglide.com/*`（www → 非 www）。
  - 结果：两边互相 307/308，导致资源加载失败，页面可能出现“纯黑/无内容”的假象。

**影响**:
- 只要重定向死循环存在，头像/favicon/静态资源都会加载失败，用户体验和 SEO 都会受影响。

**待办**:
- ✅ 选择 **非 www** 为主域名的前提下：到 Cloudflare 关闭/删除 “非 www → www” 的跳转规则，只保留 Vercel 的 “www → 非 www”。
- （可选）Cloudflare 清缓存（Purge）后再验证 `https://yieldglide.com/favicon.ico` 与 `https://yieldglide.com/avatars/buffett.jpg` 返回 200 且不再跳转。

## 2026-08-09（第八十九批）

### 构建方法现状与反爬调研结论（用户要求记录，后续再优化）
**背景**: 用户反馈鳄鱼画像风格仍有偏差，追问"能否让 AI 绕过反爬抓正文"。本批对全部免费绕过路径做了实测，并确认后续优化方向。用户拍板：付费方案与用户提供资料都排除，当前方法先记录留档。

**当前构建方法（三层）**:
1. 预置 JSON（presetMasters.js，28人）：本地秒出档案卡，0 token，覆盖高频人物
2. 配方在线构建（recipes.js + virtual-master）：命中配方走定制多关键词检索（含 site: 站内限定、反向验证词、年份拆分、噪音过滤、相关性排序、人工校准 hint），搜索+抓正文已并行化（10~16s）
3. 通用流水线兜底：未命中配方的陌生人物走默认"搜索→简报→建模"

**反爬实测结论（2026-08-09，当前网络环境）**:
- 直接 HTTP 抓知乎：403 + JS 加密签名（zh-zse-ck）❌
- 无头浏览器渲染知乎：40362 风控（要求登录/摇一摇）❌
- jina reader 渲染代理：HTTP 000 连不上 ❌
- Bing 搜索/快照：302 循环 / 连接重置 / 网络挂起 ❌
- 百度：200 但对该人物无索引（只返回古生物"寒武纪"）❌
- 搜狗：弹验证码 ❌；360：空结果 ❌；GitHub API：无相关仓库 ❌
- **根因**：人物已退乎原文消失 + 知乎/雪球主动对抗机器 + 当前网络对国外搜索引擎不稳定，三层叠加

**关键事实**：v2 构建曾成功（称号"周期价值守望者"、挖到真名"陈泽鑫"、央企/省国资委选股三原则），靠的是**搜索引擎恰好返回的知乎/雪球标题+摘要**，说明"摘要路径"可行但运气成分大、不稳定。

**已讨论/未落地的优化思路**:
- 多次采样构建：重新构建自动跑 2~3 次，合并去重摘要再喂模型（免费，+10~30s）
- 已知线索反查：把 v2 挖到的确切标题（如「寒武纪的鳄鱼：一位中国式价值投资者的思想体系」）当精确搜索词反查
- 提示词升级：借鉴"舆情研究总监"思路——素材分层（本人原话 vs 他人评价）、原话带引号引用、信源分层解构（粉丝/路人/黑粉/同行）、时间线矛盾标注、不脑补（personaPrompt 已部分升级，输出格式不变）
- 稳定优先：抓不到就少用几条，宁朴素不脑补
- 付费方案（博查/Tavily 等搜索 API）与用户提供资料，**用户明确排除**

**待办（下次优化）**: ①多次采样+已知线索反查落地；②配方库扩充（Dang大/DeepVan 等半匿名人物）；③搜索源稳定性（网络环境改善后再验证 Bing/jina）；④鳄鱼画像最终校准需用户确认"哪些细节像/不像"。
