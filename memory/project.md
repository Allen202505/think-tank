# 项目基本信息

## 项目名称
大师吵股（think-tank）- AI 投资大师智囊团

## 项目定位
一个 AI 投资决策辅助平台：汇聚巴菲特、芒格等世界顶级投资大师，通过 AI 模拟大师群体辩论/解读，为用户的投资决策提供多角度专业参考。

## 技术栈
- **框架**: Next.js 16.4.3（App Router）
- **语言**: React 18
- **部署**: 腾讯云 Lighthouse（中国香港，Docker + 服务器自动拉取）
- **小程序**: 微信原生小程序「大师吵股」+ 自有 Next.js 服务器直连（2026-11-24 扩展六种研究工具，AppID 复用 FITRY 主体）
- **AI**: DeepSeek（.env.local 存 key，不入库）；每位未配置 Key 的访客默认 2 次免费体验，用尽后引导配置自己的 API Key；「跟踪大师动态」使用 DeepSeek Search / Fetch + JSON mode
- **行情数据源**: 东财 → 腾讯证券 → 新浪（A 股实时行情与日 K 多级兜底）

## 能力模块（左侧纵向 Tab）
1. **大师PK**：用户提问，多大师群聊 PK / 单聊；支持流派筛选、邀请大师、举手提问
2. **大师实盘联赛**：单一公开赛模式；2026-09-14 开赛、10 万元、仅 A 股；首批六位已故历史投机大师，也支持用户邀请指定大师参赛并附人物简介；详情内统一查看当前持仓、下一交易日计划变动、持仓历史与策略历史
3. **大师的选股池**：预置大师池 + 导入/搜寻股票池；我的股票池支持单股移除；宽表支持 0-5 列自定义冻结和底部横向滚动；现价与今日表现使用实时批量行情，盘中自动刷新，今日/区间统计（等权 vs 上证指数）、上涨天数、持仓价、持仓温度计（0-100 分档：滚烫/温热/常温/偏凉/冰冷）
4. **巴菲特的早餐**：新闻解读（粘贴链接/文本，快速/深度两种模式，事件穿透 8 步框架，大师圆桌依次发言）
5. **跟踪大师动态（2026-10-19 重新上线）**：DeepSeek Search 发现大师近 30 天公开原帖/报道，Fetch 补全可访问网页正文，AI 提炼投资线索；按 A/B/C 证据等级标注，雪球/知乎 WAF 无法绕过时保留原始链接
6. **行业周期分析**：定位行业周期、公司周期与股票位置
7. **上证指数脱水（2026-11-20）**：一级入口位于「行业周期分析」与「功能箱」之间；可自由组合行业与个股剔除，展示官方/当前方案两卡、指数对比走势、全 A 股涨跌家数大盘和实际剔除清单，并新增全 A 股涨跌家数大盘
8. **功能箱**：统一收纳鱼大基础面研究、芒格财报、缠中说禅、纳瓦尔知识学堂、选股策略大赏、供应链瓶颈分析，内部按紧凑 Tab 胶囊切换；鱼大基础面研究位于第一个 Tab、为默认入口，并提供按股票归档的本地历史分析。选股策略大赏归档 18 条方法型策略并支持公开链接提取；供应链瓶颈分析接入 Serenity 卡脖子六步框架并自动回填板块与候选行情
9. **分享入口已下线（2026-10-13）**：侧栏「分享给好友」「入群反馈问题建议」、结果区「分享链接」「分享海报」全部移除；历史已生成的 `/share/<id>` 只读快照仍可访问，但平台不再提供任何生成分享链接的入口
10. **微信小程序「大师吵股」**：首页与统一研究工作台提供新闻分析、行业周期、上证指数脱水、基本面研究、供应链瓶颈、芒格读财报六种公开研究工具，并保留财经圆桌与公开资讯学习卡片；不提供交易指令、目标价、收益预测、交易开户或支付

### 线上链路稳定性（2026-09-30）

- A 股实时行情以东方财富为主源、腾讯行情为备用源；东财 push2 在跨境线路返回 502 时，行业周期、缠论、股票池等模块自动降级，不因单一数据源不可用而整体失败。
- 行情源按 secid 的市场位区分代码（`1.000001` 上证指数、`0.000001` 平安银行），腾讯兜底同样按市场位取 `sh/sz/bj`，避免同号代码串标的把指数写成个股价格；实时报价与日线偏离异常时按日线展示。
- Supabase Auth/REST 通过站点同源 `/api/supabase/*` 代理访问；用户浏览器不再直接连接 `*.supabase.co`，降低大陆网络链路抖动导致的 `Failed to fetch`。
- 行情缺失等上游不可用错误使用 503 和结构化 JSON，避免 Cloudflare 将 502 响应体替换成不可读的网关文本。

### 芒格教你读财报（A 股财报侦查 v1）
- 芒格主分析会先经过「财报侦查诊断 Skill」的证据排查，再写解读正文，避免只做泛泛点评。
- 芒格回答区下方新增独立模块「一页纸财务诊断清单」：顶部提炼核心矛盾、主要风险和重点线索；主清单固定为「优先级 / 侦查问题 / 关键证据 / 侦查判断 / 下一步核查」五列。
- 每条诊断均使用自然语言侦查问题，下一步统一为「查什么 → 看什么 → 判断什么」；支持展开证据详情、单条继续追问芒格，并在底部显示 3 个继续调查问题和数据缺口。
- 优先级按边际变化而非静态指标排序：首次出现/显著恶化升为 P0，明显改善降为 P1 并追问持续性，长期无变化的旧问题降为背景风险。
- 状态文案改为「异常信号 / 重点核查 / 数据不足 / 暂未发现明显异常」，异常只作为排查信号，不作为造假结论。
- A 股自动接入东财完整资产负债表、利润表、现金流量表和主要指标；同时从最新年报/审计报告抽取应收账款、存货、合同负债、其他应收款、资本开支、关联交易、会计政策等附注片段。
- 每个诊断项保留来源；结构化报表、年报附注、数据不足会明确区分。异常只作为风险信号，不能直接推导造假结论。
- 港股、美股暂不接入本轮证据链，后续分别用 SEC XBRL 和 HKEX 年报方案推进。

### 上证指数脱水（2026-11-20）

- 页面：`src/components/IndexDewater.js` + `src/components/IndexDewater.module.css`，桌面左侧、移动端底栏与功能大厅入口均位于「行业周期分析」和「功能箱」之间，URL 为 `?tab=index-dewater`。
- 核心交互：行业多选（银行、证券、保险、石油石化、煤炭、白酒、房地产、建筑装饰 + 全部细行业）、股票名称/代码搜索、6 个快捷个股、行业与个股自动去重、上证样本资格校验。
- 顶部两卡动态跟随筛选：官方指数、当前方案同除数剩余点位。点位差使用“低于/高于官方多少点”，不展示 pp；所有数据不使用千位分隔符。
- 脱水条件默认银行，通过顶部小入口打开右侧浮层配置；移除银行脱水/银行+中国石油快捷方案。页面每次首次打开默认近一年区间，自定义区间默认预填近一年起止日期。
- 页面已移除当前方案结论、独立分析区间模块、剩余股票区间表现卡、点位贡献榜和数据口径大段说明。
- 新增全 A 股（沪、深、北）涨跌家数大盘：支持今天/昨天/近7天/一个月/三个月/半年/一年/自定义，时间组件仅控制大盘；统计下跌 5000/4000/3000 家以上的天数、竖向柱状分布、截止日下跌家数排名和上证单日跌幅排名；柱状图与阈值卡同行，今日数据改为紧凑摘要行；阈值卡天数为主，占比放右侧。
- 走势图统一为“上证指数 VS 脱水后上证指数”，固定取近一年，位于大盘上方，不随大盘时间组件变化；图中脱水终点与顶部剩余点位对齐。
- 结果结构：动态两卡、指数对比走势、涨跌家数大盘、实际剔除明细、侧边脱水条件浮层。
- 计算边界：权重使用东财 f21 流通市值，全样本合计与上证指数 f117 对齐，避免 A+H 公司的 H 股混入权重；V1 使用当前沪市 A/B 股样本，未接入历史成分股和历史股本，页面与接口统一标注为“复刻口径”。
- 多源降级：样本优先东财，失败时切新浪沪市 A 股榜单与行业板块；指数/个股日线按东财 → 腾讯 → 新浪降级，并在页面标注本次数据来源。
- 接口与测试：`POST /api/index-dewater`、`POST /api/market-breadth`；`scripts/index-dewater.test.mjs` 与 `scripts/market-breadth.test.mjs` 覆盖脱水计算、多源解析、家数阈值、分布桶和排名。
- 涨跌家数快照：`src/data/marketBreadthHistory.json`，通过 `npm run update:breadth` 重新生成。接口会缓存实时沪深北全 A 股列表 2 分钟，并以指数实时行情日期覆盖当天；脱水图同步补入上证指数和剔除个股的腾讯实时行情，避免交易时段仍显示上一交易日。

## 知乎内容运营（2026-09-23）

- 运营目标：通过每天一篇投资认知中短文，为 `yieldglide.com` 带来自然流量，并引导用户完成一次具体功能体验。
- 总规划入口：`memory/zhihu-content.md`。
- 文章归档：`content/zhihu/YYYY-MM-DD-<topic_id>-<slug>.md`。
- 首发节奏：30 天排期，每篇只承接一个主功能；正文前 70% 提供独立价值，结尾再软转化。
- 主要承接功能：大师PK、巴菲特的早餐、芒格读财报、行业周期分析、大师的选股池、大师实盘联赛和功能箱（含选股策略大赏与供应链瓶颈分析）。
- 合规规则：不荐股、不承诺收益、不给出目标价或确定性买卖指令；AI 大师统一标明为公开方法模拟，不代表本人发言。
- 数据追踪：外部链接统一带 `utm_source=zhihu&utm_medium=article&utm_campaign=<topic_id>`，按 24/72 小时观察阅读、收藏、评论和站内访问。
