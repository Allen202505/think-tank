# 微信小程序「大师吵股」

> 最后更新：2026-11-24

## 目标

把 Web 端已有的公开研究与分析能力收敛为微信原生小程序，统一品牌为「大师吵股」。小程序通过 `wx.login()` 获取临时 code，由自有 Next.js 服务端向微信换取 OpenID 并签发短期 Bearer Token；研究请求直接访问 `https://yieldglide.com/api/mini/*`，不再依赖微信云开发。

## 当前产品范围

- 产品名：`大师吵股`；代码中的导航标题、首页、关于、隐私和分享文案已统一。
- 原线上名称：`多棱镜笔记`。微信公众平台后台名称需要管理员手动修改，代码无法替平台完成改名。
- 研究工具：
  - 新闻分析（对应 Web 端巴菲特的早餐方法）
  - 行业周期分析
  - 上证指数脱水
  - 基本面研究
  - 供应链瓶颈分析
  - 芒格教你读财报
- 通识工具：
  - 财经圆桌
  - 读懂财经资讯
- 首页：深墨色品牌封面 + 暖纸色双列六工具快捷卡片 + 上证指数脱水核心数据卡；财经通识、快捷问题、方法说明和长段营销文案不再放在首页。
- 脱水详情页：展示上证指数与脱水后真实指数走势、双端区间数据、结论、主要剔除对象和口径说明。
- 本地记录：研究分析、圆桌和资讯卡片统一保存在当前设备，最多 30 条。
- 关于与隐私：说明公开数据、AI 服务、OpenID 限流和内容边界。

## 六种研究工具

### 新闻分析

- 输入：新闻标题（可选）+ 公开新闻正文 20-6000 字。
- 输出：事实分层、影响传导、逆向检验、后续观察指标、数据缺口和继续核查问题。
- 提示词继承“巴菲特的早餐”事件穿透方法，不在小程序单独暴露 Web 品牌名。

### 行业周期分析

- 输入：A 股公司名称或 6 位代码；可选补充供需、库存、价格、产能等材料。
- 数据：公开行情、财务快照和财务历史；缺失字段必须标注数据不足。
- 输出：行业周期位置、供需与价格、公司位置、拐点与反证、跟踪清单。

### 上证指数脱水

- 输入：近一/三/六/十二个月，最多 8 个固定行业组和 20 只股票代码。
- 计算：直接复用 `buildIndexDewaterReport`，不经过 AI。
- 输出：官方点位与区间收益、同除数剩余点位、独立脱水收益、实际剔除数量、主要剔除对象和数据口径。
- 该工具不消耗 AI 每日额度，但仍受每分钟请求限流。

### 基本面研究

- 输入：公司名称或代码；可选研究关注点。
- 数据：公开行情、财务快照；A 股额外读取财务历史。
- 输出：生意模式、增长与盈利质量、现金流与资产负债、竞争优势、风险与反证、结论边界。
- 框架评分仅表示研究完整度或基本面质量，不代表买卖建议。

### 供应链瓶颈分析

- 输入：产业链/板块名称、市场范围（自动/A股/港股/美股/全球）、补充关注。
- 框架：复用 `src/lib/stockChoke.js` 的 Serenity 六步法和七条排除规则。
- 输出：供应链地图、关键卡点、多空证据、时间维度、候选对象、数据缺口。
- 小程序归一化层把模型可能返回的 0-10 瓶颈分统一换算为 0-100，避免展示成 9/100。

### 芒格教你读财报

- 输入：公开 HTML/PDF 财报链接，或直接粘贴至少 200 字财报原文；可选补充关注。
- 链接文本抽取最大 12000 字；PDF 解析按需动态加载。
- 输出：三张表、利润含金量、资产负债风险、资本配置、逆向排雷、附注核验问题。
- AI 输出触发交易建议或收益预测安全规则时自动重写一次，仍不合格则拒绝展示。

## 数据流

```text
微信小程序
  ├─ 本地历史：wx.setStorageSync
  ├─ wx.login() → POST /api/mini/session
  └─ Authorization: Bearer <短期令牌>
          ↓
      https://yieldglide.com
          ├─ 服务端调用微信 jscode2session
          ├─ 签发 2 小时 HMAC 会话令牌
          ├─ /api/mini/debate | reading | research
          ├─ 校验工具白名单与字段长度
          ├─ 交易指令/收益预测拦截
          ├─ 公开行情、财务、指数数据或 AI
          ├─ 统一结构化结果
          └─ 输出安全检查
```

## 合规与安全规则

- 仍然禁止输入或输出买入、卖出、加仓、减仓、持有等交易指令。
- 仍然禁止目标价、止损止盈位、收益预测、稳赚承诺。
- 公司名称或代码只在行业周期、基本面、指数脱水和财报研究中作为研究对象使用，不放宽交易建议限制。
- 小程序通过微信登录 code 换取 2 小时短期 Bearer Token；Web API 拒绝缺失、过期或签名被篡改的令牌。旧 HMAC 请求头仅保留兼容，不是当前客户端链路。
- 每日 AI 次数默认 8 次，由 `MINI_DAILY_FREE_LIMIT` 调整；指数脱水不占 AI 次数。
- 输入正文不写入业务数据库；OpenID 仅做哈希后的进程内限流。
- 公开数据源包括东方财富、腾讯证券、新浪财经和 Yahoo Finance；页面明确提示数据延迟、缺失和口径差异。

## 合规风险

本次新增公司、行业、指数和财报分析，已经超出旧版“纯财经通识”的产品范围。微信公众平台的服务类目、主体资质和审核尺度必须在提交前重新确认：

- 不应沿用旧版“仅财经通识”的审核口径。
- 不应在未确认资质时声称这些能力当然符合个人主体类目。
- 如果平台要求金融或证券相关资质而当前主体无法提供，应收敛功能或改用具备资质的主体。
- 代码内的免责声明不能替代平台类目和主体资质。
