# 项目基本信息

## 项目名称
大师吵股（think-tank）- AI 投资大师智囊团

## 项目定位
一个 AI 投资决策辅助平台：汇聚巴菲特、芒格等世界顶级投资大师，通过 AI 模拟大师群体辩论/解读，为用户的投资决策提供多角度专业参考。

## 技术栈
- **框架**: Next.js 14.2.5（App Router）
- **语言**: React 18
- **部署**: Vercel
- **AI**: DeepSeek（.env.local 存 key，不入库）
- **行情数据源**: 东财 → 腾讯 → 新浪（三级兜底，日K）

## 能力模块（左侧纵向 Tab）
1. **大师PK**：用户提问，多大师群聊 PK / 单聊；支持流派筛选、邀请大师、举手提问
2. **大师实盘联赛**：单一公开赛模式；2026-09-14 开赛、10 万元、仅 A 股；首批六位已故历史投机大师，也支持用户邀请指定大师参赛并附人物简介
3. **大师的选股池**：预置大师池 + 导入/搜寻股票池；今日/区间统计（等权 vs 沪深300）、上涨天数、持仓价
4. **巴菲特的早餐**：新闻解读（粘贴链接/文本，快速/深度两种模式，事件穿透 8 步框架，大师圆桌依次发言）
5. **行业周期分析**：定位行业周期、公司周期与股票位置
6. **功能箱**：统一收纳芒格财报、缠中说禅、纳瓦尔知识学堂、鱼大基础面研究，内部按紧凑 Tab 胶囊切换

### 芒格教你读财报（A 股财报侦查 v1）
- 芒格主分析会先经过「财报侦查诊断 Skill」的证据排查，再写解读正文，避免只做泛泛点评。
- 芒格回答区下方新增独立模块「一页纸财务诊断清单」，展示 P0-P2 诊断项、状态、核心发现、下一步验证和 3 个继续调查问题。
- A 股自动接入东财完整资产负债表、利润表、现金流量表和主要指标；同时从最新年报/审计报告抽取应收账款、存货、合同负债、其他应收款、资本开支、关联交易、会计政策等附注片段。
- 每个诊断项保留来源；结构化报表、年报附注、数据不足会明确区分。异常只作为风险信号，不能直接推导造假结论。
- 港股、美股暂不接入本轮证据链，后续分别用 SEC XBRL 和 HKEX 年报方案推进。

## 设计约定（用户强偏好）
- 暖米白 + 暗金学院风、衬线标题、克制编辑感、无毛玻璃
- 所有功能 Tab 共享左侧纵向导航，页面间距/标题字号保持一致
- 圆角纪律：卡片小圆角、按钮胶囊，不搞中间值
- 改完必须浏览器实测，用户反馈「没有效果」时先复现再断言

## 部署与仓库
- GitHub: github.com/Allen202505/think-tank（main）
- 部署：Vercel 已绑定该仓库，push 到 main 即自动触发部署、自动出线上链接，无需每次询问/手动部署；`DEEPSEEK_API_KEY`、Supabase 等必要环境变量已在 Vercel 配置好
- 本地开发：npm run dev（默认 3000，本机常用 3210）
