# 多棱镜笔记 · 微信小程序提审包

> 生成日期：2026-09-19
> 适用主体：个人开发者
> 提审版本：`1.0.0`

## 一、审核定位

本版本是财经通识学习工具，不是完整 Web 产品。审核时统一按以下口径说明：

- 用户输入财经概念，小程序从价值、逆向、成长、宏观和风险五个视角生成学习笔记。
- 用户粘贴公开财经材料，小程序整理事实、概念、影响维度和不确定性。
- 全部内容只作学习辅助，不提供证券期货投资咨询、交易建议或收益预测。
- 无行情、选股、持仓、交易、开户、支付、广告和公开发布功能。

## 二、服务类目

官方类目表：<https://developers.weixin.qq.com/miniprogram/product/material/>

2. 二级：`教育信息展示`

备选补充类目：

1. 一级：`工具`
2. 二级：`信息查询`

不要选择或申请“金融业-证券/期货”“金融业-证券/期货投资咨询”“金融业-股票信息服务平台”。这些类目不在个人主体开放范围，且需要相应的金融业务许可证或平台资质。

## 五、审核演示路径

1. 打开首页，确认页面明确写明“不提供荐买荐卖和收益预测”。
2. 进入“财经圆桌”，输入：`什么是安全边际？`
3. 保留默认三个视角，点击“生成圆桌笔记”。
4. 展示生成后的多视角内容、继续思考问题和学习提示。
5. 进入“读懂财经资讯”，点击“填入示例”，生成学习卡片。
6. 进入“关于与边界”，展示不做荐买荐卖、不做收益预测、不接交易支付的说明。

不要在审核录屏或截图中输入股票代码、买卖问题或真实个人信息。

## 六、当前提审风险

1. 即使按通识教育定位，AI 生成的财经内容仍可能被人工审核重点检查。页面文案、关键词和演示内容必须始终避开荐买荐卖、收益预测和具体证券评价。
2. 个人主体类目和审核尺度会动态变化，最终以微信公众平台提交时展示的类目与材料要求为准。
3. 名称已注册为“多棱镜笔记”，简称“多棱镜”；后续如平台要求改名，需要同步替换小程序名称、导航标题、首页、关于页和分享文案，避免名称不一致。
4. 如果审核要求企业资质或要求删除某类财经内容，应继续收敛为“财经概念词典 / 阅读卡片”，不要尝试借用金融类目绕过主体限制。
