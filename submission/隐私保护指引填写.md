# 微信公众平台隐私保护指引填写建议

以下文字用于微信公众平台“用户隐私保护指引”或“小程序用户隐私保护指引”配置，实际字段以平台当前表单为准。

## 开发者处理的信息

### 1. 用户输入内容

- 信息类型：用户主动填写或粘贴的文本。
- 使用目的：生成本次财经通识学习笔记或资讯摘要。
- 处理方式：仅在用户主动提交后，通过微信云函数转发至本项目的 AI 服务接口；业务数据库不保存问题正文。
- 用户控制：用户可以不上传、随时退出，本地学习记录可随时清除。

### 2. 微信用户标识（OpenID）

- 信息类型：微信云函数运行时可获取的 OpenID。
- 使用目的：防止恶意刷量，执行每日免费次数限制。
- 处理方式：服务端先进行 SHA-256 哈希，仅在内存中保存与当天计数相关的短期哈希值；不用于用户画像、推荐或营销，不写入业务数据库。

## 不收集的信息

- 不收集手机号、身份证、银行卡或支付信息。
- 不收集精确位置、通讯录、聊天记录、相机、相册或麦克风内容。
- 不收集证券账户、持仓、交易记录或资产信息。

## 第三方服务

可能涉及的第三方处理方：

1. 微信云开发：承载小程序云函数及其必要的平台运行日志。
2. 本项目部署与网络服务：处理小程序云函数发起的 HTTPS API 请求。
3. AI 模型服务：处理用户主动提交的文本，以生成本次学习内容。

平台与服务商可能按照其合规规则保留必要的运行和安全日志。业务系统不将用户输入用于训练自有模型。

## 用户权利

- 用户无需注册即可使用主要功能。
- 用户可以在“关于与边界”中清除当前设备的全部学习记录。
- 用户可以通过项目公开反馈地址提出隐私问题或删除请求。

