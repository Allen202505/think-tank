### 部署后：大师头像丢失 + 重定向死循环（ERR_TOO_MANY_REDIRECTS）
**背景**:
- 部署后部分大师真实头像丢失（图片加载失败）。
- 浏览器 Console 报错：`Failed to load resource: net::ERR_TOO_MANY_REDIRECTS`，涉及 `/avatars/*.jpg` 与 `/favicon.ico`。

**决策**:
- 头像资源统一使用 ASCII 路径 `/avatars/*`，避免中文路径 `/头像/*` 在部分部署/CDN 环境兼容性问题。
- 站点规范域名继续统一为 **非 www**：`https://yieldglide.com/`。

**实现**:
- 代码侧（已推送到 GitHub）：
  - `src/data/masters.js`：预置大师头像从 `/头像/*.jpg` 改为 `/avatars/*.jpg`。
  - `scripts/sync-avatars.mjs`：构建前把 `public/头像` 同步复制到 `public/avatars`。
  - `package.json`：新增 `prebuild` 执行同步脚本。
- 排查发现线上重定向互相打架导致死循环：
  - Cloudflare：将 `yieldglide.com/*` 重定向到 `www.yieldglide.com/*`（非 www → www）。
  - Vercel（`vercel.json`）：将 `www.yieldglide.com/*` 重定向到 `yieldglide.com/*`（www → 非 www）。
  - 结果：两边互相 307/308，导致资源加载失败，页面可能出现“纯黑/无内容”的假象。

**影响**:
- 只要重定向死循环存在，头像/favicon/静态资源都会加载失败，用户体验和 SEO 都会受影响。

**待办**:
- ✅ 选择 **非 www** 为主域名的前提下：到 Cloudflare 关闭/删除 “非 www → www” 的跳转规则，只保留 Vercel 的 “www → 非 www”。
- （可选）Cloudflare 清缓存（Purge）后再验证 `https://yieldglide.com/favicon.ico` 与 `https://yieldglide.com/avatars/buffett.jpg` 返回 200 且不再跳转。

**背景**: 用户问"中钢国际还值得持有吗"，大师们一直引用 2025 年数据。排查：中钢国际不在内置词典，且原解析只认词典/代码/美股 ticker，**快照为空** → 模型只能用训练记忆（旧数据）。A 股数据源本身没问题（东财能拿到 000928 的 2026 一季报）。

**待办**:
- 部分公司 2026 中报/半年报尚未披露或东财未更新时，快照会显示最新已披露报告期（如 2026 一季报），属正常。

## 2026-08-08（第六批）

### AI 信息层梳理：辩论前用 LLM 提取公司名 + 无公司名友好提示
**背景**: 用户指出启发式公司名识别仍脆弱（如"解读一下双环科技这家公司"会失败），并建议正式辩论前先做一次"信息层梳理"；同时担心"没预置名字就查不到"。

**实现**:
- `marketData.js`：新增 `extractCompaniesViaLLM()`——辩论前先用 DeepSeek 提取问题里的公司/股票（中文名/代码/英文名），再逐个走东财搜索核实（A股优先），结果按 query 缓存 1 小时；LLM 失败或无结果时回落到启发式（后缀+分段+剥问法词）。
- `quoteContext.js`：主入口改为 `getQuoteContextInfo()` 返回 `{ snapshot, notice }`；识别不到公司且问题含股票关键词时，返回提示"请补充公司名称或代码"；`getQuoteContext()` 保留兼容。
- 新增 `POST /api/context`：前端发起辩论前调用一次，生成快照 + 提示。
- `page.js`：`go()` 先调 /api/context 做信息层梳理，快照存入 ref 随每条请求带给 /api/chat（避免每条都重新解析）；追问也合并新公司的快照；识别不到公司时在输入区显示提示条。
- `route.js`：优先使用前端传入的 `snapshot`，否则按 query 现拉（向后兼容）。

**影响**:
- 任意公司名（含"解读一下XX""能不能给我讲讲XX这只股票"等绕口问法）都能稳定识别。
- 问题里确实没提公司名时，界面会明确提示补充名称/代码，而不是让大师凭记忆瞎编。
- 快照只在辩论开始前生成一次，后续请求全部走缓存，速度不受影响。

**待办**:
- 追问如提到全新公司，会合并该公司的快照（已实现）；若追问涉及复杂指代（"那家做纯碱的公司"），仍建议用户带名称。

## 2026-08-08（第十一批）

### 分享海报 v2.1 修复：undefined / 乱码折行 / 观点区大空白 / 内容溢出
**背景**: 用户实际生成海报发现：观点行出现"undefined"、乱码折行、观点与正文间大块空白、内容溢出卡片框线。

**原因** (`src/lib/poster.js`)：
1. undefined：`wrapLines` 在"单行就溢出"边界返回空数组，取 `kpLines[0]` 为 undefined 直接画上
2. 乱码折行：`wrapLines` 按"数字/非数字"分词，无数字的长文本=单个 token 无法折行且截断逻辑在空数组时失效
3. 大空白：卡片高度公式把观点区预留 84px，但实际只画 30px 高 → 中间空一大块
4. 溢出：卡片高度算小了 → 正文画到框外

**修复**：
- `wrapLines` 重写为**逐字折行 + 数字(含单位)保持原子不拆行**；截断必加"…"，任何非空文本至少返回一行
- 观点标签最多折 2 行，卡片高度按**实际测量行数**计算（观点行数、正文行数、留白精确求和）
- 新增 `clean()` 过滤模型输出的 "undefined"/"null" 脏值（观点/共识/风险）
- 卡片绘制改用游标推进，与高度计算一致

**验证**: Node 单测 5 组用例（超长无数字 1/2/3 行、含数字 3 行、短文本）——行数正确、数字不拆行、无空数组/undefined、无超宽行。

**待办**:
- 用户实际生成后再看视觉效果，需要的话继续微调字号/间距。
