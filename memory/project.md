# 项目基本信息

## 项目名称
大师吵股（think-tank）- AI 投资大师智囊团

## 项目定位
一个 AI 投资决策辅助平台：汇聚巴菲特、芒格等世界顶级投资大师，通过 AI 模拟大师群体辩论/解读，为用户的投资决策提供多角度专业参考。

## 技术栈
- **框架**: Next.js 14.2.5（App Router）
- **语言**: React 18
- **部署**: Vercel
- **小程序**: 微信原生小程序 + 微信云开发云函数（个人主体提审版，2026-09-19 新增）
- **AI**: DeepSeek（.env.local 存 key，不入库）
- **行情数据源**: 东财 → 腾讯 → 新浪（三级兜底，日K）

## 能力模块（左侧纵向 Tab）
1. **大师PK**：用户提问，多大师群聊 PK / 单聊；支持流派筛选、邀请大师、举手提问
2. **大师实盘联赛**：单一公开赛模式；2026-09-14 开赛、10 万元、仅 A 股；首批六位已故历史投机大师，也支持用户邀请指定大师参赛并附人物简介；详情内统一查看当前持仓、下一交易日计划变动、持仓历史与策略历史
3. **大师的选股池**：预置大师池 + 导入/搜寻股票池；我的股票池支持单股移除；宽表支持 0-5 列自定义冻结和顶部/底部同步横向滚动；今日/区间统计（等权 vs 沪深300）、上涨天数、持仓价
4. **巴菲特的早餐**：新闻解读（粘贴链接/文本，快速/深度两种模式，事件穿透 8 步框架，大师圆桌依次发言）
5. **行业周期分析**：定位行业周期、公司周期与股票位置
6. **功能箱**：统一收纳鱼大基础面研究、芒格财报、缠中说禅、纳瓦尔知识学堂、选股策略大赏，内部按紧凑 Tab 胶囊切换；鱼大基础面研究位于第一个 Tab、为默认入口，并提供按股票归档的本地历史分析。选股策略大赏归档 18 条方法型策略并支持公开链接提取
7. **微信小程序提审版**：个人主体可提审的“财经通识学习 + 公开资讯卡片”轻量版；不含行情、选股、财报诊断、联赛、交易、支付或荐买荐卖能力

### 微信小程序提审版

- 入口代码：`miniprogram/`；云函数代理：`cloudfunctions/mini-api/`。
- 页面：首页、财经圆桌、读懂财经资讯、学习记录、记录详情、关于与边界、隐私保护说明。
- 数据链路：小程序 → 微信云函数签名代理 → `yieldglide.com/api/mini/*` → AI 模型。
- 个人主体类目建议：教育服务-教育信息展示；可按审核意见补充工具-信息查询。
- 合规边界：个人主体不能选择金融业类目；提审包不得加入证券期货投资咨询、行情、选股、交易或收益预测。

### 芒格教你读财报（A 股财报侦查 v1）
- 芒格主分析会先经过「财报侦查诊断 Skill」的证据排查，再写解读正文，避免只做泛泛点评。
- 芒格回答区下方新增独立模块「一页纸财务诊断清单」：顶部提炼核心矛盾、主要风险和重点线索；主清单固定为「优先级 / 侦查问题 / 关键证据 / 侦查判断 / 下一步核查」五列。
- 每条诊断均使用自然语言侦查问题，下一步统一为「查什么 → 看什么 → 判断什么」；支持展开证据详情、单条继续追问芒格，并在底部显示 3 个继续调查问题和数据缺口。
- 优先级按边际变化而非静态指标排序：首次出现/显著恶化升为 P0，明显改善降为 P1 并追问持续性，长期无变化的旧问题降为背景风险。
- 状态文案改为「异常信号 / 重点核查 / 数据不足 / 暂未发现明显异常」，异常只作为排查信号，不作为造假结论。
- A 股自动接入东财完整资产负债表、利润表、现金流量表和主要指标；同时从最新年报/审计报告抽取应收账款、存货、合同负债、其他应收款、资本开支、关联交易、会计政策等附注片段。
- 每个诊断项保留来源；结构化报表、年报附注、数据不足会明确区分。异常只作为风险信号，不能直接推导造假结论。
- 港股、美股暂不接入本轮证据链，后续分别用 SEC XBRL 和 HKEX 年报方案推进。

## 设计约定（用户强偏好）
- 暖米白 + 暗金学院风、衬线标题、克制编辑感、无毛玻璃
- 所有功能 Tab 共享左侧纵向导航，页面间距/标题字号保持一致
- 圆角纪律：卡片小圆角、按钮胶囊，不搞中间值
- 改完必须浏览器实测，用户反馈「没有效果」时先复现再断言

## 部署与仓库
- GitHub: github.com/Allen202505/think-tank（main）
- 部署：Vercel 已绑定该仓库，push 到 main 即自动触发部署、自动出线上链接，无需每次询问/手动部署；`DEEPSEEK_API_KEY`、Supabase 等必要环境变量已在 Vercel 配置好
- 小程序：Vercel 与微信云函数需配置相同的 `MINI_PROXY_SECRET`；云环境 ID 与真实 AppID 由开发者账号配置，详见 `miniprogram/README.md`
- 本地开发：npm run dev（默认 3000，本机常用 3210）

## 知乎内容运营（2026-09-23）

- 运营目标：通过每天一篇投资认知中短文，为 `yieldglide.com` 带来自然流量，并引导用户完成一次具体功能体验。
- 总规划入口：`memory/zhihu-content.md`。
- 文章归档：`content/zhihu/YYYY-MM-DD-<topic_id>-<slug>.md`。
- 首发节奏：30 天排期，每篇只承接一个主功能；正文前 70% 提供独立价值，结尾再软转化。
- 主要承接功能：大师PK、巴菲特的早餐、芒格读财报、行业周期分析、大师的选股池、大师实盘联赛和功能箱（含选股策略大赏）。
- 合规规则：不荐股、不承诺收益、不给出目标价或确定性买卖指令；AI 大师统一标明为公开方法模拟，不代表本人发言。
- 数据追踪：外部链接统一带 `utm_source=zhihu&utm_medium=article&utm_campaign=<topic_id>`，按 24/72 小时观察阅读、收藏、评论和站内访问。
