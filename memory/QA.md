## 3. 全局功能说明

### 3.1 导航

桌面端左侧导航顺序：

1. 大师PK
2. 大师实盘联赛
3. 大师的选股池
4. 巴菲特的早餐
5. 行业周期分析
6. 功能箱
   - 芒格教你读财报
   - 缠中说禅看短线
   - 纳瓦尔知识学堂
   - 鱼大基础面研究

移动端底部导航和功能大厅保持相同顺序。

### 3.2 AI 调用与免费额度

- 无用户 Key：默认 10 次免费体验，使用站长服务端 Key。
- 站长默认模型为 `deepseek-flash`（DeepSeek-V4.1-Flash）；请求显式关闭思考模式，避免多轮工具调用额外计费与 `reasoning_content` 回传问题。
- 第 10 次可用；第 11 次触发 `ensureAiReady()`，弹出 AI 设置。
- 有用户 Key：不消耗免费次数，直接使用用户配置。
- 免费次数同时写入：
  - `localStorage`：`thinktank_free_quota`
  - Cookie：同名
  - 取两者较大值，防止刷新重置。
- 服务端另有未带用户 Key 的防滥用兜底：
  - 当前设置为每 IP 每日 40 次。
  - 跨接口共享计数。
  - 第 41 次返回 HTTP `429`。
  - 多实例/Vercel 环境为尽力而为，本地单实例测试可精确验证。

### 3.3 分享机制

- 左侧底部“分享给好友”位于“入群聊一聊”上方。
- 两个按钮高度一致。
- 分享按钮使用分享图标，带轻微摇摆和光圈动效。
- 用户主动完成完整功能输出后计数：
  - 第 1 次不弹提示。
  - 第 2 次完整输出后，顶部出现一次分享提示。
  - 只出现一次，记录在 `thinktank_share_prompt_seen_v1`。
- 分享面板默认文案包含网站地址和推荐语。
- 关闭方式：
  - 点击面板外空白处。
  - 点击右上角关闭按钮。
  - 按 `Esc`。

### 3.4 数据真实性原则

- 行情、财报、估值、行业指数来自公开数据层。
- 行业周期模块中，行业库存、现货价格、开工率等无法自动获取时，必须标为“数据不足”或“待验证”。
- AI 不得编造精确数字。
- 缺失数据会降低周期评分覆盖率与置信度。

## 8. 芒格教你读财报

### 功能细节

- 支持财报链接、PDF/文本附件和补充说明。
- 输出财报解读、结构化诊断和一页纸财务诊断清单；原系统数据核验收进清单内部。
- 清单顶部展示核心矛盾、主要风险、重点线索；主清单使用「优先级 / 侦查问题 / 关键证据 / 侦查判断 / 下一步核查」五列。
- 顶部三类结论独立成「本期核心结论」区，必须是完整可读句子，不能只罗列数字；公司画像只保留 2-6 字短标签。
- 侦查问题使用自然语言；下一步固定为「查什么 → 看什么 → 判断什么」；每条可展开证据详情并发起定向追问。
- 状态显示为「异常信号 / 重点核查 / 数据不足 / 暂未发现明显异常」，不显示股票评级含义。
- 优先级采用边际变化优先：首次出现/显著恶化可进 P0，明显改善降为 P1 并追问改善持续性，持续无变化的旧问题降为背景风险。
- 状态胶囊与领域标签分开成行；表格外框和优先级左侧竖线已移除，结论卡使用图标和提亮色块增强层级。
- 支持举手追问。
- 结果本地持久化。
- A 股自动拉取完整资产负债表、利润表、现金流量表和主要指标，不再只依赖少量历史指标。
- 自动定位最新年报/审计报告并抽取附注片段：应收、存货、合同负债、其他应收款、商誉、在建工程、资本开支、关联交易、会计政策、关键审计事项。
- 芒格主分析先使用财报侦查 Skill 的证据排查结果，再写正文；诊断项必须标注来源，数据不足显示 `⚪`。
- 当前仅 A 股接入证据包；港股/美股沿用原有降级路径。

## 21. 大师实盘联赛

### 功能细节

- 入口：桌面左侧、移动端底部导航、功能大厅；URL 状态为 `?tab=master-league`。
- 只有公开赛一种模式，不再显示公开赛/擂台赛切换 Tab。
- 平台预置六位已故历史投机大师：利弗莫尔、威科夫、达瓦斯、勒布、科斯托拉尼、巴鲁克。
- 用户可点击“邀请大师”打开侧边抽屉，填写提示词或上传 Skill 创建大师参赛。
- 新邀请的大师统一获得 100,000 元初始额度，并直接进入公开赛排名。
- 排行榜只按累计收益率排序，收益绝对值不参与主排序。
- 每位大师提供一句话简介；大师详情页提供时代、原始方法和 A 股映射。
- 今日大师策略与大师互评策略共用一个白色面板，顶部头像切换后同步切换策略和评论。
- 无标的「持有」表示“不调整仓位”，不是卖出到 0%；策略列表显示执行日前的实际持仓股票，空仓时显示“当前空仓”，明细固定显示“保持现有仓位”，不再显示“目标仓位 0%”。
- 互评按当前展示策略的 `decisionDate` 查询，而不是浏览器当天日期；因此前一晚收盘后生成的次日策略，隔天仍会展示对应那批评论。空结果会短时自动重试，兼容收盘任务尚未跑完的窗口。
- 排名表整行可点击，支持键盘 `Enter` / 空格进入大师详情。
- 行情失败时不伪造交易，部分标的缺失时相关策略标记为“未执行”。
- 公共底表：`supabase/master_league.sql` 定义比赛、账户、持仓、决策和评论表；配置 `SUPABASE_SERVICE_ROLE_KEY` 后自动同步。
- 邀请底表 `master_league_invites` 允许匿名读取，其他用户的邀请对所有访客可见并长期留存；登录用户只能创建/更新/删除自己的邀请，管理员可删除任意邀请。
- 管理员身份由 `profiles.is_admin` 控制；站长可在 Supabase SQL Editor 将自己的账号设为管理员。
- 管理员进入邀请大师详情可见「管理员审核」区：邀请人、发布时间、提交的提示词和 Skill 内容。
- 管理员删除他人邀请时会先写入 `master_league_invite_blocks` 黑名单再删除数据，对方换浏览器也无法重新发布同一位大师；邀请人删除自己的邀请是直接删除。
- 底表未初始化（`PGRST205` / `42P01`）或旧库没有 `profiles.is_admin`（`42703`）时静默降级，页面不暴露数据库报错。
- 邀请提交失败时抽屉内显示可读文案；发布按钮进入「发布中…」状态并禁用。
- 初次读取公开赛数据时显示两颗 CSS 3D 骰子滚动/摇晃，正文只保留「正在同步真实行情与大师账户，请稍候…」；右上角读取胶囊使用迷你骰子图标，`prefers-reduced-motion` 下关闭动画。

## 22. 大师智能体感知层（零 token 地基）

### 功能细节

- 目的：让每位大师能按需查全市场数据（而不是被塞一份固定候选池），为后续「独立智能体自主决策」打底。
- 数据流转：全市场数据只在服务端流转 + 缓存，**只有工具查询结果进模型上下文**，所以 5000+ 只股票不产生 token 成本。
- 工具清单：`get_market_overview`（指数/行业强弱/涨停池）、`screen_stocks`（按行业/涨跌幅/成交额/换手/市值/PE 筛选排序）、`get_stock_quote`（单股快照）、`get_stock_history`（日线）、`get_my_positions`（自己持仓）。
- 行业别名：`医药/芯片/券商/白酒/军工/新能源车` 等口语词会映射到数据源的细分行业名；筛不到时返回可读提示而不是空数组。
- 多源冗余：新浪（榜单/行业/日线）+ 东财（指数/涨停池/单股/日线）+ 腾讯（日线）互为备源；单源失败不抛给用户。
- 口径约束：指数涨跌家数按指数分别给出（不做会重复计数的跨指数相加）；涨停池取不到时返回 `null`，不假装 0 家；数据源失败时在 `dataWarnings` 里如实说明，而不是返回「0 个行业上涨」这种误导性结果。
- 调试入口（零 LLM）：`GET /api/master-league/tools`、`GET /api/master-league/tools?tool=<name>&<参数>`、`POST /api/master-league/tools`。
